# Public design and capability references

Reviewed for this independent implementation on 2026-09-09. These are external reference sources, not bundled code, copied product assets, compatibility contracts or claims that Stratum implements the entire products described.

- Palantir AIP overview: https://www.palantir.com/docs/foundry/aip/overview/
- AIP Logic overview: https://www.palantir.com/docs/foundry/logic/overview/
- AIP Chatbot Studio overview: https://www.palantir.com/docs/foundry/chatbot-studio/overview/
- Public P&ID analysis workflow: https://aip.palantir.com/workflow/preview-aip-util-pid
- WebGPU specification: https://www.w3.org/TR/webgpu/
- WGSL specification: https://www.w3.org/TR/WGSL/
- Mozilla PDF.js examples: https://mozilla.github.io/pdf.js/examples/

The reference platform describes ontology-connected logic, assistants, evaluations and governed actions. Stratum implements a local subset with original layout details, icons, example data and branding. The P&ID workspace explicitly connects component annotation, a structured diagram model, BOM review and ontology publication rather than presenting a general chat screen as diagram analysis.
